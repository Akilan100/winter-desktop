# Winter Desktop for Linux (Hyprland + Quickshell + Snowhush)

A native 144Hz VSync multi-season desktop overlay for Wayland (Hyprland), inspired by KoiArt desktop experiences.

## Features
- **True 144Hz VSync Smoothness**: Driven by QtQuick `FrameAnimation` locked to display refresh rate.
- **Multi-Weather Modes (`SUPER + ALT + W` to toggle)**:
  - **Snow (`Mode 0`)**: White powdery flakes, crystal stars (`❄`), and smooth ground/window snow accumulation.
  - **Autumn Leaves (`Mode 1`)**: Tumbling maple and oak leaves (`🍁`, `🍂`, `🍃`) in warm autumn hues.
  - **Rain (`Mode 2`)**: High-velocity slanted rain streaks with wet translucent sheen.
  - **Cherry Blossom (`Mode 3`)**: Soft pink sakura petals (`🌸`) with gentle rotational drift.
- **Interactive Snow Physics**:
  - Right-click and drag to roll snowballs, build snowmen, and customize decorations.
  - Yellow bulldozer/snowplow with manual controls (drive left/right, pause, honk, blade lift, dismiss).
  - Window-to-window snow shedding and projectile throwing when dragging/throwing windows.
- **Zero Autostart Footprint**: Toggling off completely terminates all overlay processes with zero background footprint.

## Installation & Usage
```bash
# Toggle overlay on/off
SUPER + ALT + W
```
